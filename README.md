# Basketry

Market basket analysis on Amazon product reviews using association rule mining.

This project treats each reviewer as a basket and each reviewed product as an item. It prepares the review data, filters to positive ratings, removes single-item baskets, and mines frequent itemsets and association rules. It includes a custom Apriori implementation, comparisons with `mlxtend` Apriori and FP-Growth, a notebook, and a small web app for exploring the results.

## Setup

```bash
git clone https://github.com/pborkar2602-netizen/amazon-market-basket-apriori.git
cd amazon-market-basket-apriori
python -m venv .venv
# Linux/macOS
source .venv/bin/activate
# Windows
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Open http://localhost:8000. The application starts with `data/demo_small.csv`, so no download is required for the default demo. You can also upload a CSV from the page.

To regenerate the larger sample from the original dataset:

```bash
python data/prepare_data.py
```

To run the tests:

```bash
python -m pytest -q
```

## Dataset

- Source: Amazon Reviews 2023, McAuley Lab (UCSD)
- Category: Grocery and Gourmet Food, 5-core subset
- `data/reviews_sample.csv`: sampled reviewer transactions generated by `data/prepare_data.py`
- `data/demo_small.csv`: small demo subset used for tests and the app

The project keeps both sample files tracked unless a future download exceeds the repository size policy. If the larger Amazon sample is removed, it can be regenerated with `python data/prepare_data.py`.

Citation:

Hou, Y., Li, J., He, Z., Yan, A., Chen, X., and McAuley, J. (2024). Bridging Language and Items for Retrieval and Recommendation. arXiv:2403.03952.

## Limitations

Reviews are not purchases. A reviewer may have bought items at different times or from different sellers, and a review does not necessarily correspond to a single shopping basket. The rules therefore describe co-review and co-interest patterns, not direct checkout transactions.
